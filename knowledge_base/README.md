# Knowledge Base — внутренняя база знаний

Внутренние знания, которые **готовятся заранее и всегда доступны** агентам:

- прошлые образовательные программы и методички;
- шаблоны АЦР (ПК по 273-ФЗ / приказ №499, общеразвивающая по приказу №629);
- справочник нормативки и профстандартов с кодами трудовых функций (Reference DB);
- эмбеддинги этих материалов для семантического поиска (Vector DB).

Агенты обращаются сюда через инструменты `rag_retrieve` и `normative_lookup`. Справочник не генеративный — отдаёт только реальные записи, чтобы исключить выдуманные приказы и коды.
