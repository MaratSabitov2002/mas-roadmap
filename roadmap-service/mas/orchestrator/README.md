# Orchestrator — сборка всего пайплайна

Здесь собирается весь пайплайн МАС: маршрутизация между агентами, состояние диалога, гейты «человек в контуре» (утверждение каркаса, финальный черновик), точечная пересборка затронутых подграфов. Работает с графом документа через `graph_ops` и вызывает агентов (`agent1`, `agent2`, …).

## Файлы

- `pipeline.py` — сборка всего пайплайна МАС
- `prompts.py` — промпты
- `tools.py` — инструменты оркестратора
- `schemas.py` — Pydantic-схемы входа/выхода
