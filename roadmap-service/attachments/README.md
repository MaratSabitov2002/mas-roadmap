# Attachments — чтение приложенных материалов

Инструмент МАС (`attachment_read`): парсит документы, которые пользователь приложил в чат (docx, pdf, профстандарты, прошлые программы), и отдаёт их агентам как дополнительный контекст.

- Материалы помечаются как внешний контекст. Дословно копировать их в результат запрещено.
- Агенты подключают инструмент через свой `tools.py`.
