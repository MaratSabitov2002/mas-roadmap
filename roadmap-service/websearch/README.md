# Websearch — поиск в браузере

Не отдельный сервис, а инструмент МАС (`web_search`): поиск во внешних источниках (актуальные практики ИТ, профстандарты) с обязательной проверкой подлинности источника (`source_verify`). Неподтверждённые источники помечаются `unconfirmed`.

Агенты подключают его через свой `tools.py`.
