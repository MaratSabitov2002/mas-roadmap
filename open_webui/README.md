# Open WebUI — интерфейс

Пользовательский интерфейс решения на базе **OpenWebUI**: чат, в котором методист описывает задачу, прикладывает референсы, утверждает каркас и вносит точечные правки.

- МАС подключается к OpenWebUI как Pipeline (OpenAI-совместимый эндпоинт).
- Здесь же — лёгкая панель/команды для просмотра и редактирования графа документа.
- Через интерфейс проходят гейты «человек в контуре»: утверждение каркаса и финальная проверка черновика.
