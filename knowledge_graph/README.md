# Knowledge Graph — сервис графовой БД

Сервис графовой базы данных, в которой хранятся **графы документов** для составления учебной документации.

- Документ программы хранится не как текст, а как граф: главы — сообщества узлов (`module`, `competency`, `goal`), подглавы — подграфы (`theme`, `lecture`, `assessment`), листья — `hours`, `test_item`, `seminar_task`, `source`.
- Рёбра несут смысл проверок: `competency → theme`, `competency → assessment`, `module → theme → hours`, `* → source`.
- Поддерживает CRUD узлов и рёбер, версии, diff, откат и инвалидацию подграфа для точечной пересборки.
- Граф целиком сериализуется в JSON — это и выходной формат, и механизм версионирования.

Агенты МАС читают и пишут граф через инструменты `graph_ops`, `graph_diff`, `invalidate_subgraph`.
